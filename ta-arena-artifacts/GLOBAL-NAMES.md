# Global names and places (TA Arena)

The games will be used worldwide, in English only. Replace every name and place below in content/*.json and in engine/ (template.html, hub-template.html, build.py). Keep each character's role and personality. Change only the name.

Match case. Use whole-word matching, so "Ma" does not change "Mama" or "Madrid" (there are none, but check). After each batch of replacements, read the sentence: if a word is now awkward ("Mum's call" is fine; "Mum, Mum" is not), fix the sentence, not the mapping.
